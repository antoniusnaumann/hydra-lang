    fs

    Filesystem paths, inspection, reading, and writing.

    use fs, then fs::read(...). Alternatively, use fs as files or use fs as *.

    size, modified, read, lines, and list return value, reason. Success has reason :null. Their fallback overloads return fallback, reason on failure; calls without a fallback crash. A single binding keeps only the value. Failure reasons →

    Paths#

    fs::join(base, parts*)#

    → string

    Join and normalize path components. join("a", "/b") yields "a/b". Removes .; preserves ...

    fs::parent(path)#

    → string

    Parent directory; "." if the path has no directory component.

    fs::name(path)#

    → string

    Final path component, including its extension.

    fs::stem(path)#

    → string

    Final component without its last extension.

    fs::extension(path)#

    → string

    Last extension without its dot; "" if absent.

    fs::absolute(path)#

    → string

    Resolve against the working directory. Does not require existence or resolve symlinks.

    Locations#

    fs::cwd()#

    → string

    Current working directory.

    fs::home()#

    → string

    Current user’s home directory. Crashes if unavailable.

    fs::temp()#

    → string

    System temporary directory. Does not create a file or directory.

    Inspect#

    fs::exists(path)#

    → boolean

    Whether the path exists and can be inspected. Follows symlinks.

    fs::is_file(path)#

    → boolean

    Whether the path is a regular file. False if absent or inaccessible.

    fs::is_dir(path)#

    → boolean

    Whether the path is a directory. False if absent or inaccessible.

    fs::size(path)#

    fs::size(path, fallback)
    → bytes, reason

    Size from filesystem metadata, in bytes. Without a fallback, errors crash.

    fs::modified(path)#

    fs::modified(path, fallback)
    → seconds, reason

    Modification time as Unix seconds, including fractions. Without a fallback, errors crash.

    Read#

    fs::read(path)#

    fs::read(path, fallback)
    → string, reason

    Read the whole file as UTF-8. Without a fallback, read and encoding errors crash.

    fs::lines(path)#

    fs::lines(path, fallback)
    → list, reason

    Read UTF-8 lines, without line endings. Without a fallback, errors crash.

    fs::list(dir, *, match = "*", recursive = :false)#

    fs::list(dir, fallback, *, match = "*", recursive = :false)
    → list, reason

    List matching entries as paths joined to dir. Sort within each directory; recurse depth-first when requested. Patterns support * and ?. Without a fallback, errors crash.

    Write#

    fs::write(path, text, *, mode = :replace, parents = :true)#

    → path, bytes

    Write text; return the path and UTF-8 byte count. :replace truncates, :append appends, :new requires a new file. Creates parent directories by default.

    fs::copy(source, target, *, overwrite = :true, parents = :true)#

    → target

    Copy a file or directory tree. Overwrite and create parent directories by default. Other failures crash.

    fs::move(source, target, *, overwrite = :false, parents = :true)#

    → target

    Rename a file or directory. Create parents by default; existing targets require overwrite = :true. Cross-filesystem moves may fail.

    fs::remove(path, *, recursive = :false)#

    → boolean

    Remove a file or empty directory; recursive = :true removes a directory tree. False if absent; other failures crash.

    fs::make_dir(path, *, parents = :true)#

    → path

    Create a directory and, by default, its parents. An existing directory is fine; other failures crash.
