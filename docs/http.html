    http

    HTTP and HTTPS requests, text responses, and binary downloads.

    use http, then http::name(...). Imports support aliases and as *.

    Method shorthands share request options and fallback behavior. Use request for custom methods. Headers are an atom-keyed dict of strings or lists of strings. Response header names are lowercase, with lists preserving repeated values. TLS certificates are verified; redirects are followed up to 10. timeout is a positive total duration in seconds; max_bytes caps the decoded body (16 MiB by default, buffered in memory). Each call has a strict and a fallback overload. Operational failures report a reason or crash; invalid arguments always crash.

    Waiting calls run off the scheduler so other trails can progress. Normal trail cancellation lets an in-flight call finish. Each waiting call currently uses an OS helper thread.

    use http
use json
body := json::stringify { :ready : :true }
response, reason := http::patch "https://example.com/item", body, :null,
	headers = { :content-type : "application/json" }
if reason == :null
	print response.status
else
	print reason
end

    Requests#

    http::request(method, url, *, body = :null, headers = {}, timeout = 30, max_bytes = 16777216)#

    http::request(method, url, fallback, *, body = :null, headers = {}, timeout = 30, max_bytes = 16777216)
    → response, reason

    Send a method string or atom, with an optional UTF-8 body. Response fields are .status, .headers, .body, and final .url. HTTP error statuses remain ordinary responses.

    http::get(url, *, headers = {}, timeout = 30, max_bytes = 16777216)#

    http::get(url, fallback, *, headers = {}, timeout = 30, max_bytes = 16777216)
    → response, reason

    GET shorthand for request. Response body must be UTF-8.

    http::post(url, body, *, headers = {}, timeout = 30, max_bytes = 16777216)#

    http::post(url, body, fallback, *, headers = {}, timeout = 30, max_bytes = 16777216)
    → response, reason

    POST a UTF-8 string. Set content-type explicitly; use json::stringify for JSON payloads.

    http::head(url, *, headers = {}, timeout = 30, max_bytes = 16777216)#

    http::head(url, fallback, *, headers = {}, timeout = 30, max_bytes = 16777216)
    → response, reason

    HEAD shorthand. Return status and headers with an empty .body, even when content-length describes a nonempty resource.

    http::put(url, body, *, headers = {}, timeout = 30, max_bytes = 16777216)#

    http::put(url, body, fallback, *, headers = {}, timeout = 30, max_bytes = 16777216)
    → response, reason

    PUT a UTF-8 string. Set content-type explicitly; use json::stringify for JSON payloads.

    http::patch(url, body, *, headers = {}, timeout = 30, max_bytes = 16777216)#

    http::patch(url, body, fallback, *, headers = {}, timeout = 30, max_bytes = 16777216)
    → response, reason

    PATCH with a UTF-8 string. Set the content-type required by the server’s patch format.

    http::delete(url, *, body = :null, headers = {}, timeout = 30, max_bytes = 16777216)#

    http::delete(url, fallback, *, body = :null, headers = {}, timeout = 30, max_bytes = 16777216)
    → response, reason

    DELETE shorthand, with an optional named body.

    http::options(url, *, body = :null, headers = {}, timeout = 30, max_bytes = 16777216)#

    http::options(url, fallback, *, body = :null, headers = {}, timeout = 30, max_bytes = 16777216)
    → response, reason

    OPTIONS shorthand, with an optional named body. Inspect response headers for supported operations.

    http::connect(url, *, headers = {}, timeout = 30, max_bytes = 16777216)#

    http::connect(url, fallback, *, headers = {}, timeout = 30, max_bytes = 16777216)
    → response, reason

    Send CONNECT using the URL’s authority as the request target. Return the handshake response and close the connection; tunnel streams are not exposed.

    http::trace(url, *, headers = {}, timeout = 30, max_bytes = 16777216)#

    http::trace(url, fallback, *, headers = {}, timeout = 30, max_bytes = 16777216)
    → response, reason

    TRACE shorthand. Return the server’s diagnostic response.

    http::download(url, path, *, headers = {}, timeout = 30, max_bytes = 16777216)#

    http::download(url, path, fallback, *, headers = {}, timeout = 30, max_bytes = 16777216)
    → path, reason

    GET binary data to a file. Require a 2xx status, create parent directories, and replace the target only after the complete bounded download succeeds. Failure leaves an existing target intact.
