    env

    Script arguments, environment variables, and the host platform.

    use env, then env::name(...). Imports support aliases and as *.

    Run hydra run script.hy -- arg1 arg2. Interpreter options go before --. This module does not mutate the process environment.

    use env
name := env::get "USER", "friend"
print "Hello, \(name)"

    Environment#

    env::args()#

    → list

    Arguments after --, excluding the script name. Embedding hosts supply these in VM options.

    env::get(name)#

    env::get(name, fallback)
    → string, reason

    Read a variable. Missing names return fallback, :not_found; non-Unicode values return fallback, :encoding. Without a fallback, failures crash. Invalid names always crash.

    env::all()#

    → dict

    Snapshot Unicode environment variables, sorted by name. Keys are atoms; variables with non-Unicode names or values are omitted.

    env::platform()#

    → atom

    Host OS, such as :macos, :linux, or :windows.
