    cli

    Argument parsers with generated help, typed options, and subcommands.

    use cli, then cli::name(...). Imports support aliases and as *.

    Types: :string (default), :int (exact integers), :float (finite). Actions: :store, :store_true, :store_false, :store_const, :append, :append_const, :count, :help, :version. Use const for constant actions or an option with nargs="?"; version supplies version text. nargs accepts a positive count, "?", "*", or "+". choices checks converted values. Absent values default to :null; flags to false/true, counts to 0, repeated values to []. String defaults are converted. Supports --name=value, -n3, -vv, negative numbers, and -- to end options. Long options require exact spelling. Parent options precede subcommands. Configure each child before attaching it; later edits do not alter the attached copy.

    use cli
p := cli::parser(description = "Greet someone")
cli::add_argument(&p, "name", help = "Who to greet")
cli::add_argument(&p, "-n", "--count", type = :int, default = 1)
args, extras := cli::parse_args(p, strict = :false)
print "Hello, \(args.name)!"

    Build#

    cli::parser(*, prog = :null, description = "", epilog = "", add_help = :true)#

    → parser

    Create a copyable parser. prog defaults to the script filename; add_help registers -h and --help.

    cli::add_argument(&parser, names*, help = "", dest = :null, type = :string, default = :null, required = :false, action = :store, nargs = :null, choices = :null, metavar = :null, const = :null, version = "")#

    → :null

    Add one positional name or option aliases through &parser. Return fields use atom keys; default dest strips leading dashes and changes hyphens to underscores.

    cli::add_subparser(&parser, name, child, *, help = "", dest = "command", required = :true)#

    → :null

    Attach a copy of a configured child parser. The chosen command name goes in dest; child fields merge into the result. Commands are required by default.

    Parse#

    cli::parse_args(parser, args = :null, *, strict = :true)#

    → dict, extras

    Parse explicit string arguments, or script arguments after -- when omitted. With strict = :true, reject unknown arguments and return [] as extras on success; strict = :false returns unknown arguments in extras. Print help/version to stdout and stop with status 0; print input errors to stderr and stop with status 2.

    Help#

    cli::format_help(parser)#

    → string

    Render usage, description, arguments, choices, commands, and epilog without printing.

    cli::format_usage(parser)#

    → string

    Render the compact usage line without printing.
