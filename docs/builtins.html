    Builtins

    Global functions, available without an import.

    Ordinary, shadowable functions. f := print keeps the function; ::print selects the builtin explicitly. Call syntax →

    Control functions only construct values. Consumed results stay data; unconsumed results reach a handler. Loop and return requests crash when no local handler exists. Handlers →

    Values#

    print(value, terminator = "\n")#

    → :null

    Write one value as text, followed by terminator. Use "" to omit the newline.

    len(value)#

    → number

    Count list elements, dict entries, or Unicode characters in a string.

    has(container, key)#

    → boolean

    Test for a dict key or list index. Negative indices count from the end.

    get(container, key, fallback)#

    → value

    Read a dict key or list index, returning fallback when absent. Does not insert anything.

    push(&list, value)#

    → number

    Append a copied value to a list; return its new length. The list argument must use &.

    Control#

    return(values*)#

    → [:return, …values]

    Construct a return request. Unconsumed, return its payload from the current function; an empty request returns :null.

    break()#

    → :break

    Construct a loop-stop request. Unconsumed, stop the nearest loop in this function; a parallel loop stops as a whole.

    continue()#

    → :continue

    Construct an iteration-stop request. Unconsumed, skip the rest of this iteration; a parallel iteration ends its trail.

    reject(msg = :null)#

    → [:reject, msg]

    Construct a rejection. Unconsumed in a function, try its next overload. Unhandled exhaustion reports all refusal messages and fails.

    exit(code = 0)#

    → [:exit, code]

    Construct an exit request. Unconsumed, stop the program with an integer status from 0 through 255.

    panic(msg)#

    → [:panic, msg]

    Construct a panic request. Unconsumed, stop the program with a rendered message, call trace, and status 1.

    Concurrency#

    alive()#

    → boolean

    Whether the current trail is still live. Returns :true outside a trail.

    channel()#

    → number

    The current trail’s zero-based index in its block. Requires a trail.

    send(value, to*, mode = :wait)#

    → boolean

    Send to sibling trails; omit destinations for any sibling. Default :wait waits for receipt; :detach queues one message; :broadcast queues a copy per eligible sibling. False if none remain. Requires a trail.

    receive(from*)#

    → value, channel

    Wait for a sibling’s message and its sender index. Omit sources for any sibling. Returns :null, :null once none can send. Requires a trail.
