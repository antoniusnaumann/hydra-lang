    list

    Eager list operations, with Rust-style callbacks and itertools conveniences.

    use list, then list::name(...). Imports support aliases and as *.

    All operations are eager; no iter() or collect(). Inputs keep value semantics. Callbacks run in order, may capture variables or suspend, and their results are consumed as data. Predicates use normal truthiness. Ordering rejects mixed types, dicts, functions, and NaN; atoms sort by name. Counts and indices are nonnegative integers. Combinations/permutations of size zero give [[]]; size beyond length gives []. Expanding native operations cap output at one million elements; windows and combinatorial selections also count copied entries.

    use list
values := list::range(10)
    .list::map(fn(x) x * x)
    .list::filter(fn(x) x > 20)
print values
yes, no := list::partition(values, fn(x) x % 2 == 0)
print list::windows(yes, 2)

    Create#

    list::range(start, end = :null, step = 1)#

    → list

    Exclusive integer range. One argument means 0 through start-1; negative steps count down. Step must be nonzero; integers must be exactly representable.

    list::repeat(value, count)#

    → list

    Copy value count times.

    Transform#

    list::map(items, f)#

    → list

    Apply f(item) to each item.

    list::filter(items, f)#

    → list

    Keep items whose f(item) is truthy.

    list::filter_map(items, f)#

    → list

    Map and omit only :null; retain :false and zero.

    list::flat_map(items, f)#

    → list

    Map each item to a list, then flatten one level.

    list::flatten(items)#

    → list

    Concatenate one level of nested lists.

    list::enumerate(items)#

    → list

    Produce [index, value] pairs, starting at zero.

    list::rev(items)#

    → list

    Reverse item order.

    Combine#

    list::chain(left, right)#

    → list

    Concatenate two lists.

    list::zip(left, right)#

    → list

    Pair corresponding items; stop at the shorter list.

    list::unzip(items)#

    → left, right

    Split a list of two-element pairs into two returned lists.

    list::interleave(left, right)#

    → list

    Alternate left and right items, retaining the longer list’s remainder.

    list::cartesian_product(left, right)#

    → list

    Every [left, right] pair, in left-major order.

    list::intersperse(items, separator)#

    → list

    Insert separator between adjacent items.

    Slice#

    list::take(items, count)#

    → list

    Keep at most count leading items.

    list::skip(items, count)#

    → list

    Omit at most count leading items.

    list::step_by(items, step)#

    → list

    Keep every step-th item, starting with the first. Step must be positive.

    list::take_while(items, f)#

    → list

    Keep the leading items satisfying f; stop at the first failure.

    list::skip_while(items, f)#

    → list

    Skip the leading items satisfying f, then keep everything else.

    list::map_while(items, f)#

    → list

    Map until f first returns :null; omit that result.

    list::chunks(items, size)#

    → list

    Non-overlapping lists of positive size; include the final partial chunk.

    list::windows(items, size)#

    → list

    Overlapping lists of positive size; include complete windows only.

    Search#

    list::first(items)#

    → value or :null

    First item, or :null for an empty list.

    list::last(items)#

    → value or :null

    Last item, or :null for an empty list.

    list::nth(items, index)#

    → value or :null

    Item at a nonnegative zero-based index, or :null if absent.

    list::find(items, f)#

    → value or :null

    First item satisfying f, or :null.

    list::find_map(items, f)#

    → value or :null

    First non-null f(item), stopping immediately.

    list::position(items, f)#

    → index or :null

    First zero-based index satisfying f.

    list::rposition(items, f)#

    → index or :null

    Last zero-based index satisfying f; search backwards.

    list::any(items, f)#

    → boolean

    Whether any item satisfies f; short-circuit. False for an empty list.

    list::all(items, f)#

    → boolean

    Whether every item satisfies f; short-circuit. True for an empty list.

    Reduce#

    list::count(items)#

    → number

    Number of items; equivalent to len(items).

    list::fold(items, initial, f)#

    → value

    Apply f(accumulator, item) from left to right, starting with initial.

    list::reduce(items, f)#

    → value or :null

    Fold using the first item as accumulator; :null for an empty list.

    list::sum(items)#

    → number

    Sum numeric items; zero for an empty list.

    list::product(items)#

    → number

    Multiply numeric items; one for an empty list.

    list::join(items, separator = "")#

    → string

    Render items as text and join with separator.

    Effects#

    list::for_each(items, f)#

    → :null

    Call f(item) in order, consuming and discarding each result.

    list::inspect(items, f)#

    → list

    Call f(item) in order for side effects; return the original list.

    Group#

    list::partition(items, f)#

    → matching, other

    Return two lists, preserving order, partitioned by f(item).

    list::unique(items)#

    → list

    Keep the first occurrence of each deeply equal value.

    list::unique_by(items, f)#

    → list

    Keep the first item for each deeply equal f(item) key.

    list::dedup(items)#

    → list

    Remove consecutive duplicate values.

    list::dedup_by(items, f)#

    → list

    Remove an item when f(last_retained, item) is truthy.

    list::dedup_by_key(items, f)#

    → list

    Remove consecutive items with equal f(item) keys.

    list::counts(items)#

    → list

    Return [value, count] pairs in first-occurrence order.

    list::group_by(items, f)#

    → list

    Group all equal f(item) keys as [key, items] pairs, in first-key order.

    list::chunk_by(items, f)#

    → list

    Group consecutive equal f(item) keys as [key, items] pairs.

    Order#

    list::sorted(items)#

    → list

    Stable ascending sort. Supports matching numbers, strings, atoms, or recursively ordered lists.

    list::sorted_by(items, compare)#

    → list

    Stable sort using compare(a, b): negative, zero, or positive for less, equal, or greater.

    list::sorted_by_key(items, f)#

    → list

    Stable ascending sort by f(item), evaluated once per item.

    list::min(items)#

    → value or :null

    Smallest ordered item; first wins ties. Empty gives :null.

    list::max(items)#

    → value or :null

    Largest ordered item; last wins ties. Empty gives :null.

    list::min_by(items, compare)#

    → value or :null

    Minimum by numeric comparator; first wins ties. Empty gives :null.

    list::max_by(items, compare)#

    → value or :null

    Maximum by numeric comparator; last wins ties. Empty gives :null.

    list::min_by_key(items, f)#

    → value or :null

    Minimum by f(item), evaluated once per item; first wins ties. Empty gives :null.

    list::max_by_key(items, f)#

    → value or :null

    Maximum by f(item), evaluated once per item; last wins ties. Empty gives :null.

    Combinatorics#

    list::combinations(items, size)#

    → list

    Size-item selections in input order, without replacement. Equal values at different positions remain distinct.

    list::permutations(items, size)#

    → list

    Size-item ordered selections without replacement, in input-index order.
